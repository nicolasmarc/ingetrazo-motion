# Motion (IngeTrazo extension) — work in progress
Kinematic validation of simple mechanisms (drop-leaf, drawer, folding chair, garage door).
Clean-room, GPL-3.0. Pure Python + numpy core, tested against closed-form results.
V0.1: rigid bodies, pivot, slider, driver 0-100 %, closed-loop solver, DOF, box interference, joint limits.
Run tests: `python tests/test_core.py` (or pytest).
